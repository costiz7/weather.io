## Overview

weather.io is an interactive web application that provides current weather information for any city worldwide. The application leverages a dual-API architecture to deliver accurate, location-based weather data through an intuitive and visually appealing interface.

**🚀 Deployed on Vercel** – Ensuring fast, reliable global access with automatic deployments and serverless infrastructure.

### Technical Architecture

The application employs two distinct APIs working in tandem:

- **Geocoding API** – Translates user-inputted city names into precise geographic coordinates (latitude/longitude)
- **OpenWeather API** – Retrieves comprehensive weather data based on the provided coordinates

![weather.io Interface](https://imgur.com/JMGG7Xo.png)

## Key Features

- **Location Search** – Retrieve weather data for any city globally
- **Comprehensive Weather Metrics** – View temperature, humidity, wind speed, and detailed weather conditions
- **Custom Icon Design** – All weather icons designed from scratch in Adobe Photoshop
- **Fluid Animations** – Smooth transitions and interactive elements enhance user experience
- **Responsive Layout** – Optimized for seamless performance across desktop, tablet, and mobile devices
- **Modern UI/UX** – Clean, intuitive interface designed with user accessibility in mind

## Installation & Setup

### Option 1: View Live Demo
Visit the deployed application on Vercel: [weather.io](https://weather-io-amber.vercel.app/)

### Option 2: Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/costiz7/weather.io.git
   ```

2. Navigate to the project directory:
   ```bash
   cd weather-io
   ```

3. Open `index.html` in your browser or use a local development server

4. Configure API keys (if required) in the configuration file
